# MongolPhoto

몽골 고비에서 여행 사진·드론 사진·은하수 사진 찍기 — 장비부터 촬영, 후보정까지 초보자가 따라 할 수 있는 한국어 mdBook 튜토리얼.

## 📖 책 보기

**[몽골 사진 가이드](https://ohama.github.io/MongolPhoto/)** (GitHub Pages)

## 목차

- **소개** — 여행·드론·은하수 사진의 매력, 이 책의 세 축(여행·드론·은하수), 최소 장비, 후보정 과정, 예시 사진
- **1부 · 여행 사진** — 촬영(카메라 설정·렌즈·구도/빛·현장/사람) + 코스 명소별 여행 가이드 + **여행 사진 보정**(Lightroom Classic: 현상 순서·상황별 레시피·국소 보정·파노라마/HDR·촬영 연계) + 참고 자료(튜토리얼·예시 갤러리)
- **2부 · 드론 사진·영상** — 개요·DJI Mini 5 Pro 조작/설정·항공 구도·비행/환경 + 명소별 항공 가이드 + **드론 사진 후보정** + **드론 영상 촬영·CapCut 편집**(작성 예정) + 참고 자료(규제·사양/튜토리얼·예시 갤러리) + **명소별 영상 스토리보드**(드론 2·통합 4 촬영·편집 계획, 콘셉트/작성 예정)
- **3부 · 천체사진 (은하수)** — 장비 가이드 + 기초 촬영법(노출·크롭 셔터룰·초점·RAW·타이밍·워크플로) + 가기 전 연습(집·야외) + 은하수 명소별 촬영 가이드 + **천체사진 보정**(RAW 현상→스태킹→강조→전/후) + 보너스 기법(파노라마·스타트레일·타임랩스) + 참고 자료
- **4부 · 현장 워크플로** — 세 트랙을 한 여행으로 잇는 가로 연결: 여행 전 준비(통합 패킹·촬영 계획·오프라인 앱) + 하루 현장 운용(하루 타임라인·세 카메라 오케스트레이션) + **명소별 저녁~다음날 아침 촬영 플랜**(도착~골든아워~은하수~아침을 명소별 시간 순서로) + 데이터·전원 운용(카드·현장 백업·멀티데이 전원) + 귀국 후 정리(3-2-1 백업·선별·편집 순서 허브) — 각 트랙 촬영·편집법은 1·2·3부로 링크 승계
- **부록** — 참고 자료와 독립 실전 가이드를 **네 구역**으로 정리:
  - **사진** — 카메라·렌즈 추천 · 사진 파노라마 · 파노라마 연습 · LX-254CT+XB-32 수평·파노라마(독립) · 타임랩스(카메라/폰)·연습
  - **드론** — 드론 파노라마·연습 · 일출·일몰 시간대별 사진·드론 촬영 순서
  - **천체촬영** — 은하수(카메라/폰)·연습 · 스타트레일(카메라/폰)·연습 · **페르세우스 유성우(2026년 8월, 독립)** · 천체 스태킹 소프트웨어
  - **공통** — 고비 여행 일정·달(월령) 캘린더 · 종합 장비 추천 · 현장 치트시트 · 체크리스트 · 앱·소프트웨어 · 용어 사전

## 개발

mdBook으로 작성되며 `main`에 push하면 GitHub Actions가 빌드해 `docs/`를 커밋, GitHub Pages로 배포합니다.

```sh
mdbook serve src   # 로컬 미리보기
mdbook build src   # docs/ 로 빌드
```

- 책 원문: `src/`
- 배포 산출물: `docs/` (CI가 자동 생성)
- 이미지 최적화: `scripts/optimize-images.sh`
- 기획 문서: `.planning/`
- 스카우팅 참고(개인용, 책 미포함): `google-earth-scouting.md`
