# 종합 장비 추천 (여행·드론·은하수)

세 트랙(여행 사진·드론·은하수)에 필요한 장비를 **한 페이지**에 모았습니다. 흩어진 추천을 여기서 한눈에 보세요.

> **전부 "이런 걸 고려하면 좋다"는 추천입니다.** 이미 가진 장비가 목적에 맞으면 새로 살 필요 없습니다. 이 책은 특정 판매처를 안내하지 않고, 가격은 대략적인 참고용입니다. 정확한 무게·사양·요금은 공식 자료로 확인하세요(미확인).

## 1. 카메라 · 렌즈

- 상세 예시·크롭계수 계산은 [카메라 · 렌즈 추천 목록](camera-lens-picks.md) 참고.
- 요약: **가벼운 크롭 미러리스** + **은하수용 밝은 광각(F2.8 이하)** + (여행용) **만능 줌**(예: 18-150mm급)으로 낮 상황을 폭넓게.

## 2. 삼각대 · 헤드

밤 장노출·파노라마·블루아워에 필수입니다. 여행이라 가볍되, 고비 강풍을 버틸 안정성이 필요합니다. 고를 때 기준:

| 고를 때 기준 | 메모 |
|---|---|
| **안정성 vs 무게** | 밤 장노출·바람 대비 튼튼함이 우선. 여행이라 너무 무겁지 않게 절충 |
| **센터훅** | 가방·돌을 걸어 무게 추가(고비 강풍) |
| **볼헤드** | 빠른 구도 변경·퀵릴리즈. 파노라마는 헤드 하단 파노(수평 회전) 베이스로 수평 유지 회전 |

**예: 레오포토(Leofoto) LX-254CT** — 카본 역접이(리버스 폴딩) 트래블 삼각대. 이 책의 삼각대 설명은 이 모델을 예로 진행합니다.

| 사양(검증) | 값 |
|---|---|
| 무게 | 약 1.41kg(XB-32 볼헤드 포함) / 1.12kg(다리만) |
| 최대 높이 | 약 163cm(센터컬럼 최대) |
| 최소 높이 | 약 20cm |
| 접은 길이 | 약 45cm(역접이 → 배낭 수납) |
| 내하중 | 약 8kg |
| 다리 | 4단 카본(25/22/19/16mm) · XB-32 볼헤드 세트 |

- **왜 이 급인가** — R7 + 삼양 12mm/RF 50mm 킷은 1kg 미만이라 내하중 8kg에 여유가 큽니다. 카본이라 가볍고(휴대↑), 저온에서 금속보다 손이 덜 시립니다.
- **고비 강풍** — 가벼운 트래블 삼각대는 바람에 약하므로 **센터훅에 가방·돌을 매달아** 무게를 더하고, 장노출·파노라마 땐 **센터컬럼을 내려** 낮고 안정적으로 씁니다.
- **모래·저온** — 다리 관절·잠금부에 모래가 들어가지 않게 관리하고, 밤엔 배터리·손 보온.

> 가격·재고·번들 헤드 구성은 구매처에서 재확인하세요. 미보유라면 **유사 스펙(카본·내하중 6kg↑·접이 45cm 안팎)의 트래블 삼각대**면 충분합니다 — 특정 제품 강매가 아니라 설명용 예시입니다.

- 폰 촬영도 한다면 **폰 클램프(마운트)** 별도.

## 3. 필터

| 필터 | 용도 |
|---|---|
| **ND**(감광) | 낮 영상(드론 포함) 셔터 낮추기, 낮 장노출 |
| **CPL**(편광) | 낮 풍경 반사·하늘 대비(주간 정지 사진) |
| **소프트 필터**(선택) | 은하수에서 밝은 별을 살짝 부풀려 강조 |

## 4. 릴리즈 · 인터벌 타이머

- 장노출·스타트레일·타임랩스에 유용. R7은 **RS-60E3(E3·2.5mm)** 단자.
- 외장 인터벌 릴리즈(예: SMDV T805 등) 또는 카메라 **내장 인터벌/벌브 타이머**로도 가능. 상세는 [필수 액세서리](../3-astro/1-gear/accessories.md).

## 5. 전원 · 저장

- **여분 배터리 2~3개**(밤·저온 급방전), 충전기, **대용량 파워뱅크** + 케이블.
- **메모리 카드 여유분** + 카드 케이스. 멀티데이 오프그리드 전원 운용은 [데이터·전원 운용](../4-workflow/data-power.md).

## 6. 드론 킷 (DJI Mini 5 Pro)

- **여분 배터리**(비행 시간 짧음) + 충전 허브, **ND 필터 세트**(낮 영상), **여분 프로펠러**, **드론용 microSD**.
- 규제·사양은 [DJI Mini 5 Pro 사양·튜토리얼](../2-drone/5-references/gear-tutorials.md), [몽골 드론 규제](../2-drone/5-references/mongolia-regulations.md).

## 7. 방한 · 안전 · 청소

- **방한복·장갑(터치 가능)**, **적색 헤드램프**, **렌즈 히터/성에 방지대**(김서림), 예비 배터리 **보온 주머니**.
- **블로어·렌즈 클리너**(고비 모래·먼지), 여분 렌즈캡.

## 패킹은 체크리스트로

무엇을 챙길지는 [출발 전 체크리스트](../3-astro/1-gear/checklist.md)와 [체크리스트 모음](checklists.md)에서 항목별로 점검하세요. 이 페이지는 "무엇을 왜 고르나", 체크리스트는 "빠짐없이 챙겼나" 용도입니다.
