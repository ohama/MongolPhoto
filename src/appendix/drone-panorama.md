# 몽골에서 드론 파노라마 찍기 (예: DJI Mini 5 Pro)

> 드론의 **자동 파노라마 기능**으로 몽골 고비의 넓은 풍경을 공중에서 담는 법입니다.
> 드론이 여러 장을 자동 촬영하고 앱이 이어 붙여(스티칭) 한 장을 만듭니다 — 초보도 쉽게 초광각·360°를 얻습니다.
> 설명은 **DJI Mini 5 Pro**를 예시로 들지만, 대부분의 DJI 드론이 비슷한 파노라마 모드를 갖고 있어 원리는 같습니다.
> (밤 은하수 파노라마는 드론의 저조도·장노출 한계로 부적합 — 지상 카메라의 몫입니다.)

> 🔰 몽골 전에 **합법 구역에서 파노 모드·재스티칭을 미리 연습**하세요 — [드론 파노라마 가기 전 연습](drone-panorama-practice.md).

## ⚡ 빠른 카드 (한눈에)

| 항목 | 값 |
|------|-----|
| 언제 | **바람 약할 때(주로 아침)** · **골든/블루아워** · **주간**(야간 비행 규제) |
| 모드 | Sphere(360°) / 180° / 광각 / 수직 / **Free(수동)** 중 선택 |
| 사진 형식 | **RAW(DNG)+JPEG** — 원본 프레임 보관해 나중에 고화질 재스티칭 |
| 고도 | 높을수록 스케일↑ (**규제 고도 내**) |
| 전원 | 배터리 **충분히**(사구/저온·바람에 소모↑, 중간에 끊기면 실패) |
| 안정 | 촬영 내내 **정지 호버링** — 바람에 표류하면 이음매 오류 |
| 결과 | 앱 자동 스티칭 JPEG + (권장) 컴퓨터에서 원본 재스티칭 |

> 바람이 드론 파노라마 성패의 1순위 변수입니다. 잔잔한 창을 노리세요.

## 1. 왜 몽골에서 드론 파노라마인가 — 장점

- **공중 시점 = 지상 불가능한 스케일** — 위에서 내려다봐야 보이는 **사구 능선의 물결 패턴, 절벽·바위 군락의 기하학, 초원을 가로지르는 길·강**을 담습니다.
- **자동화가 쉽다** — 드론이 알아서 여러 장을 찍고 앱이 스티칭. 복잡한 삼각대·회전 없이 초광각/360°를 얻습니다.
- **고비의 개방 지형에 최적** — 방해물 없는 광활한 지형은 공중 파노라마의 이음매가 깨끗하고 구도가 강렬합니다.
- **지상 파노라마가 못 하는 표현** — Sphere로 "리틀 플래닛", 전천구(360°) 등.

## 2. 드론 파노라마 찍는 법

### 2-1. 모드 고르기 (DJI Mini 5 Pro 기준)

| 모드 | 촬영 장수 | 쓰임 |
|------|-----------|------|
| **Sphere(구체·360°)** | 33장 | 전천구 → "리틀 플래닛"·360° 뷰 |
| **180°** | 21장 | 왜곡 적은 넓은 2D 파노라마(크롭·리프레임 쉬움) |
| **광각(Wide)** | 9장 (3×3) | 표준 와이드 한 장 |
| **수직(Vertical)** | 3장 | 세로로 긴 장면(높은 절벽·"위→아래") |
| **Free(수동)** | 수동 구도 | 직접 범위를 정하는 신규 모드 |

*(장수·명칭은 앱/펌웨어 버전에서 확인. 다른 기종은 있는 모드로 대응.)*

### 2-2. 세팅

1. **사진 형식 RAW(DNG)+JPEG** — 드론이 저장한 **원본 프레임**을 나중에 컴퓨터에서 재스티칭하면 앱 자동본보다 화질이 좋습니다.
2. **노출은 균일하게** — 역광·강한 명암차는 프레임마다 밝기가 달라져 **이음매**가 생깁니다. 빛이 고른 골든아워가 유리하고, 필요하면 노출을 고정합니다.
3. 화이트밸런스 수동 고정(자동은 프레임마다 색이 달라짐).
4. **비행 전 나침반·GPS 정상, 안전거리 확보**(절벽·사람·가축과 거리).

### 2-3. 촬영

1. 원하는 **고도·위치에서 정지 호버링**(높을수록 스케일↑, 단 규제 고도 내).
2. 앱에서 파노라마 모드 선택 → 실행. 드론이 자동으로 회전·틸트하며 여러 장 촬영.
3. **촬영이 끝날 때까지 조종간을 건드리지 말고**, 드론이 바람에 밀리지 않는지 지켜봅니다(밀리면 재촬영).
4. 완료 후 앱이 자동 스티칭한 결과를 확인. 마음에 안 들면 고도·구도·시간대를 바꿔 재시도.

### 2-4. 스티칭(고화질은 컴퓨터에서)

- 앱 자동 스티칭 JPEG는 빠르지만 화질·자유도가 제한적입니다.
- **원본 프레임(DNG)을 컴퓨터로 옮겨** Lightroom "사진 병합 → 파노라마" 또는 PTGui/Hugin(무료)로 **재스티칭**하면 해상도·관용도·이음매가 훨씬 좋습니다.

## 3. 몽골에서 언제 찍나

- **바람 약한 때(주로 이른 아침)** — 가장 중요. 경량 드론은 바람에 약하고, 다중 프레임 촬영 중 표류하면 스티칭이 어긋납니다. 고비는 바람이 세니 **잔잔한 창**을 노리세요.
- **골든아워/블루아워** — 낮은 각도의 빛이 사구·절벽에 질감과 그림자를 주고, 명암차가 줄어 **프레임 간 노출도 고르게** 됩니다.
- **주간만** — 몽골 드론 비행은 **주간·고도·시야 확보** 등 규제가 있으니 출발 전 확인하세요(야간 비행은 규제·안전상 부적합). 밤 은하수 파노라마는 드론이 아니라 **지상 카메라**로.
- **고비 환경 주의** — 모래(모터·짐벌), 저온의 배터리 급방전, 넓은 개활지의 GPS·바람.

## 4. 명소별 팁 (고비)

| 명소/피사체 | 드론 파노라마 팁 |
|---|---|
| **홍고린엘스**(대사구) | 능선 위에서 180°/광각 — 물결 패턴·긴 능선. Sphere로 사구 위 "리틀 플래닛". |
| **차강소브라가**(층리 절벽) | 절벽선을 따라 180°, 또는 **수직 모드**로 절벽 높이. |
| **바가가즈링 촐로**(바위 군락) | Sphere/광각으로 바위 분포의 기하학을 위에서. |
| **초원·길·강** | 길·강이 화면을 가로지르게 180°로 스케일·리드라인. |

## 5. 흔한 실수 (드론 파노라마 특화)

- **바람에 표류** → 프레임이 어긋나 스티칭 실패. **바람 약할 때**만.
- **노출 편차(역광·강한 명암차)** → 이음매. 고른 빛·노출 고정.
- **배터리 부족** → Sphere(33장)는 시간이 걸려 도중에 끊기면 실패. 넉넉히.
- **JPEG만 저장** → 재스티칭·현상 여지 없음. **RAW(DNG)** 병행.
- **규제·안전 무시** → 야간·고도 초과·사람 위 비행 금지. 출발 전 규제 확인.
- **저고도로 가까운 전경** → 시차로 이음매. 지나치게 낮게 붙지 않기.
