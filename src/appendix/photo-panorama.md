# 몽골에서 사진 파노라마 찍기 (카메라)

> 카메라로 여러 컷을 이어 붙여(스티칭) 만드는 **사진 파노라마**를 몽골 고비에서 찍는 법입니다.
> 삼각대에 올릴 수 있고 **수동(M)·RAW**가 되는 카메라면 어느 기종이든 됩니다.
> (드론 자동 파노라마는 성격이 달라 이 문서에서는 다루지 않습니다.)

---

## ⚡ 빠른 카드 (한눈에)

| 항목 | 값 |
|------|-----|
| 언제 | **골든아워/블루아워**(정오 직사광 ✕) · 은하수 아치는 **천문박명 후·신월** |
| 삼각대 | **필수**(수평 유지) — 바람 약할 때 |
| 모드 | **M(수동)** — 노출·초점·WB **전부 고정** |
| 조리개 | **f/8~f/11**(전체 선명·피사계심도) — 은하수는 f/2~2.8 |
| 프레임 | 카메라를 **세로(포트레이트)로 세워** 회전 → 위아래 여유↑ |
| 겹침 | 컷 사이 **30~40% 겹치게** 한 방향으로 회전 |
| 노출 | 가장 밝은 곳 기준으로 **한 번 정해 전 컷 동일** |
| 파일 | **RAW** |
| 스티칭 | Lightroom "사진 병합 → 파노라마" 또는 PTGui / Hugin(무료) |

> 넓게 = 좌우로 여러 컷. 하늘까지 크게(은하수 아치 등) = **위아래로도 여러 줄(멀티로우)**.

---

## 1. 왜 몽골에서 파노라마인가 — 장점

파노라마의 존재 이유는 "한 프레임에 안 담기는 넓이·스케일"을 담는 것입니다. 고비는 그 조건이 극단적으로 갖춰진 곳입니다.

- **광활·개방 지형** — 나무·건물 같은 방해물이 거의 없어 **지평선이 깨끗** → 스티칭이 쉽고 구도가 강렬합니다.
- **거대한 하늘·낮은 지평선** — 단일 표준 프레임에선 "허전한 벌판"이 파노라마에선 **압도적 스케일**로 바뀝니다.
- **스케일 전달** — 사구·절벽·끝없는 초원의 규모는 한 컷으로 전달이 안 됩니다. 파노라마가 "그 자리에 선 느낌"을 복원합니다.
- **고해상 결과물** — 여러 컷을 이어 붙이므로 **수천만~1억 화소급** 이미지가 되어 대형 인쇄·크롭에 유리합니다.
- **세계 최상급 다크스카이** — 광공해가 거의 없어 **은하수가 지평선에서 하늘로 걸치는 아치 파노라마**에 최적입니다(3절).

## 2. 파노라마 찍는 법

### 2-1. 준비

- **튼튼한 삼각대 + 수평 유지.** 카메라의 가상 수평계(전자 레벨)를 켜고, 회전축이 기울지 않게 맞춥니다.
- (있으면 좋음) **파노라마 헤드/노달 슬라이드** — 렌즈의 무시차점(노달포인트)을 회전축에 맞추면 **가까운 전경의 시차 오류**가 줄어 스티칭이 깔끔합니다. **전경에 가까운 피사체가 없으면(먼 풍경만)** 없어도 큰 문제 없습니다.
- 렌즈: **표준~준망원**(예: 35~50mm 상당)이 왜곡이 적고 해상도↑라 낮 풍경 파노라마에 유리합니다. **초광각**(예: 12mm 상당)은 컷 수가 적어 편하지만 왜곡·주변부 품질에 주의. 은하수 아치는 **밝은 광각**(F2.8 이하)이 유리.

### 2-2. 세팅 — "전부 고정"이 핵심

컷마다 밝기·색·초점이 달라지면 이음매가 티 납니다. **모두 수동으로 고정**하세요.

1. **M(수동) 노출** — 장면에서 가장 밝은 부분을 기준으로 노출을 정해(하이라이트 안 타게) **모든 컷 동일 값**으로.
2. **수동 초점(MF)** — 원하는 지점(원경이면 무한)에 맞추고 **고정**. 컷마다 AF가 바뀌면 안 됩니다.
3. **화이트밸런스 수동 고정**(예: 4800~5500K 낮, 3800~4200K 밤) — 자동은 컷마다 색이 달라집니다.
4. **조리개 f/8~f/11**(낮) — 전체가 선명하고 회절도 적당. 은하수는 최대개방(f/2~2.8).
5. **RAW** 저장.

### 2-3. 촬영

1. **카메라를 세로로 세워** 삼각대에 장착(가로 파노라마에서 위아래 화각을 더 확보).
2. 한쪽 끝에서 시작해 **한 방향으로 일정하게 회전**, 컷 사이 **30~40% 겹치게** 촬영.
3. **수평 유지** — 회전하는 동안 지평선 높이가 흔들리지 않게.
4. 하늘을 크게(은하수 아치·구름 큰 장면) 담으려면 **위/아래 줄도 추가(멀티로우)**, 행 사이도 겹침.
5. 시작/끝에 여유 컷을 한 장씩 더 찍어 두면 스티칭·크롭 여유가 생깁니다.

### 2-4. 스티칭(병합)

- **Lightroom Classic:** 여러 RAW 선택 → "사진 병합 → 파노라마" → **구형/원통형/원근** 투영 중 선택(넓은 장면은 보통 원통형). 병합 결과도 RAW(DNG)라 이후 현상 관용도 유지.
- **PTGui**(유료·강력) / **Hugin**(무료·오픈소스) — 컷이 많거나 멀티로우·정밀 제어에 유리.
- 병합 후: 수평 미세 보정, 크롭, 색·대비·노이즈 마무리.

## 3. 몽골에서 언제 찍나

- **골든아워(일출·일몰 전후)** — 낮은 각도의 빛이 사구·절벽에 **긴 그림자와 질감**을 만들고, 콘트라스트가 낮아 **스티칭도 쉬워집니다**. 파노라마의 최적 시간.
- **블루아워(해 진 직후/뜨기 전)** — 부드러운 색조의 넓은 하늘.
- **정오 직사광은 피하기** — 그림자가 죽어 밋밋하고, 고콘트라스트라 이음매가 티 납니다.
- **은하수 아치 파노라마** — 천문박명이 끝난 뒤, **달 없는 밤(신월~반달)**. 참고로 **이번 몽골 트립의 출발일 2026년 8월 13일은 신월**이라 트립 기간 내내 달빛이 거의 없어 은하수 아치에 이상적입니다(정확한 시각·방위는 PhotoPills/Stellarium으로 그날·그 위치 기준 확인).
- **바람 약한 때(주로 아침)** — 고비는 바람이 세서, 강풍은 삼각대 흔들림·모래·풀 흔들림으로 **스티칭을 망칩니다**. 바람 잔잔한 시간대를 노리세요.
- **빠른 구름 주의** — 구름이 빨리 흐르는 날은 컷 사이 하늘 모양이 달라져 이음매가 생깁니다.

## 4. 명소별 팁 (고비)

| 명소/피사체 | 파노라마 팁 |
|---|---|
| **홍고린엘스**(대사구) | 긴 능선·물결 패턴을 골든아워에 가로로 길게. 능선이 앵커. |
| **차강소브라가**(층리 절벽) | 수평으로 긴 절벽이라 가로 파노라마의 정석. 위에서/아래에서 두 줄. |
| **초원·게르** | 넓은 환경을 담되 **게르·낙타·나무 등 앵커**를 넣어 허전함 방지. 움직이는 가축은 경계에 두지 않기. |
| **바가가즈링 촐로**(바위 군락) | 바위를 전경 앵커로. 전경이 가까우면 노달포인트 주의. |
| **욜링암**(좁은 협곡) | 가로보다 **세로(수직) 파노라마**로 협곡 높이를 살림. |

## 5. 흔한 실수

- **노출/WB/초점을 자동으로 둠** → 컷마다 밝기·색·초점이 달라 이음매가 티 남. **전부 수동 고정.**
- **겹침 부족** → 스티칭 실패. 30~40% 확보.
- **삼각대 수평 안 맞음/바람에 흔들림** → 휘거나 어긋남.
- **움직이는 피사체가 프레임 경계에** → 유령·잘림. 사람·차·가축·날리는 모래 주의.
- **정오 직사광·전경 앵커 없음** → 넓기만 하고 밋밋. 골든아워 + 앵커.
- **JPEG로만** → 병합·현상 관용도 없음. RAW로.
