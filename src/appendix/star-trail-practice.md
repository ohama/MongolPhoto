# 스타트레일 가기 전 연습

스타트레일(별궤적)에서 실패하는 곳은 **밤하늘의 어둠**이 아니라 **워크플로**입니다 — 인터벌 타이머 설정, 야간 무한초점, 장노출 노이즈 감소(NR)를 끄는 것, 전원·이슬 관리, 그리고 수십~수백 장을 **합성**(스택)하는 과정. 이걸 몽골에서 처음 하면 반드시 실수합니다.

다행히 스타트레일은 은하수와 달리 **광공해에 관대**합니다 — 밝은 별은 도시 하늘에서도 궤적이 남습니다. 그래서 **집 옥상·베란다·마당에서도 연습이 됩니다.** 목표는 완성작이 아니라 **손에 익히기**입니다. 전체 촬영·합성 이론은 [카메라로 스타트레일 찍기](camera-star-trail.md)로 이어집니다.

---

## ⚡ 연습용 세팅 카드 (예: Canon R7)

| 항목 | 값 | 왜 |
|------|-----|-----|
| 방법 | **30초 여러 장 → 컴퓨터에서 합성(스택)** | 오늘날 표준. 한 장 실패해도 복구 |
| 모드 | **M(수동) · RAW** | 노출 고정 |
| 조리개 | **f/2.8 전후** | 별 선명·하늘 과밝음 억제 |
| 셔터 | **한 장 30초** | 오래 쌓이므로 낮게 |
| ISO | **400~1600** | 낮게 — 광해 누적 방지 |
| 장노출 NR | **반드시 OFF** | 켜면 컷 간격 2배 → 궤적이 점선처럼 끊김(1순위 실수) |
| IS(손떨림) | **OFF** | 삼각대 |
| 초점 | **라이브뷰 확대 → 무한(∞) MF, 테이프 고정** | 도중엔 못 고침 |
| 화이트밸런스 | **3800~4200K 수동 고정** | 자동은 컷마다 색이 달라짐 |
| 연속 촬영 | **내장 인터벌 타이머**(간격 최소, 연습은 20~40장) | 자동 연속 |
| 전원 | **여분/더미배터리** | 중단이 최대 실패 |

> R7 조작: 모드다이얼 **M** · 메뉴에서 **장노출 노이즈 감소 OFF** 확인 · 렌즈(또는 바디) IS OFF · **인터벌 타이머**에서 간격·매수 지정. 자세한 메뉴 위치는 [카메라로 스타트레일 찍기](camera-star-trail.md).

## 어디서 연습하나

- **집 옥상·베란다·마당 우선.** 광공해가 있어도 밝은 별은 궤적이 남으니 **워크플로 연습엔 충분**합니다.
- **북쪽 하늘이 보이는 자리**를 고르면 좋습니다. 별이 **동심원**을 그리는 중심 **북극성**은 북쪽, 고도 ≈ 그 지역 위도(한국은 약 37°, 몽골 고비는 약 44°)입니다. 정확한 위치는 PhotoPills/Stellarium으로.
- 더 어두운(별 많은) 결과를 원하면 **근교 어두운 곳**(예: 서해안·산간)에서. 단 연습의 핵심은 장소가 아니라 **인터벌·초점·NR OFF·합성**을 익히는 것입니다.
- **불빛이 지나다니지 않고**, 삼각대를 오래 두어도 되는 **안전한 자리**로.

## 연습 세션 (짧게 — 워크플로만 익히기)

본 촬영은 1~2시간이지만, 연습은 **과정 확인**이 목적이라 짧아도 됩니다.

1. **초저녁/밝을 때** 구도를 정하고 **무한초점을 잡아 테이프로 고정**합니다.
2. 세팅 카드대로 맞추고 — 특히 **장노출 NR OFF**를 재확인.
3. 인터벌 타이머로 **30초 × 20~40장**(약 10~20분)만 테스트 촬영.
4. 촬영이 도는 동안 **삼각대·케이블을 절대 건드리지 않고** 배터리·남은 매수만 확인.
5. 집에 와서 **StarStaX로 "라이튼(Lighten)" 합성 + 갭필링** → 궤적 한 장을 만듭니다. **이 합성까지 해봐야 연습이 완성**됩니다. (대안: Sequator)

## 삼각대 고정

스타트레일은 **수십 분~수 시간 미동도 없어야** 궤적이 매끄럽습니다.

- **촬영이 도는 동안 삼각대·케이블을 절대 건드리지 마세요** — 한 번의 흔들림이 전체 궤적을 망칩니다.
- **이슬·서리**엔 **렌즈워머/손난로**로 예방.
- 세우기·수평·센터훅·스파이크 발 등 삼각대 사용 전반은 [종합 장비 추천](gear-picks.md)을 따르세요(여기서 다시 설명하지 않음).

## 연습 후 점검 (이게 진짜 목적)

집에서 합성하며 **무엇이 틀어졌는지** 보는 것이 연습의 핵심입니다.

- **궤적이 점선처럼 끊겼나?** → 장노출 NR가 켜졌거나 인터벌 간격이 너무 길다. **NR OFF·간격 최소.**
- **궤적이 흔들리거나 이중인가?** → 촬영 중 삼각대를 건드렸거나 바람. 무게 추가·안 건드리기.
- **별이 흐릿/이중 초점?** → 무한초점이 어긋남. 밝을 때 잡고 **테이프 고정.**
- **중간에 멈췄나?** → 배터리 방전. 전원 확보(여분/더미배터리).
- **하늘이 점점 밝아져 별이 묻혔나?** → ISO를 낮추고 조리개를 조인다.

## 연습 체크리스트

- [ ] M · f/2.8 · 30초 · ISO 400~1600 · RAW
- [ ] **장노출 NR OFF** · IS OFF (가장 흔한 실수)
- [ ] 무한초점 잡고 **테이프 고정** · WB 3800~4200K 고정
- [ ] 인터벌 타이머 30초 × 20~40장 · 간격 최소
- [ ] 삼각대 무게·안 건드리기 · 전원 여분
- [ ] 집에서 **StarStaX 라이튼 합성 + 갭필링**까지
- [ ] 북극성(북쪽) 구도 한 번 시도 → 동심원 궤적 확인
