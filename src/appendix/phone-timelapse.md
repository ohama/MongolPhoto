# 몽골에서 휴대폰으로 타임랩스 찍기 (예: iPhone 16 Pro)

> 오랜 시간에 걸친 변화(흐르는 구름, 이동하는 그림자, 도는 별)를 **짧은 영상**으로 압축하는 것이 타임랩스입니다.
> 휴대폰은 **낮 타임랩스**(구름·해·사람)가 아주 쉽고, **밤 별 타임랩스**는 앱이 필요합니다. (삼각대·전원 필수)

---

## ⚡ 빠른 카드 (한눈에)

| 항목 | 값 |
|------|-----|
| 낮(쉬움) | 카메라 앱 **타임랩스 모드** — 자동, 버튼 하나 |
| 밤(별) | 기본 앱은 장노출이 안 됨 → **인터벌/장노출 촬영 앱**으로 여러 장 → 조립 |
| 삼각대 | **필수** — 촬영 내내 고정 |
| 전원 | **보조배터리 연결**(장시간·발열) |
| 방해요소 | **비행기 모드·방해금지·자동잠금 해제** |
| 시간 | 실제로 **수십 분~수 시간** 걸림(결과는 몇 초~십몇 초) |

---

## 1. 타임랩스란 · 왜 몽골에서

- 오래 걸리는 변화를 몇 초로 압축해 **시간을 눈에 보이게** 만듭니다.
- 고비는 **빠른 구름·넓은 초원·세계 최상급 밤하늘**이라 타임랩스에 이상적입니다.

## 2. 찍는 법

### 낮 타임랩스 — 아주 쉬움

1. **휴대폰용 삼각대**에 고정(손으로 들면 안 됨).
2. 카메라 앱을 **타임랩스** 모드로(모드를 옆으로 밀어 선택).
3. **보조배터리 연결·방해금지·자동잠금 해제** 후 **녹화 시작** → 원하는 만큼 두었다가 정지.
   - 기본 타임랩스는 **간격·노출을 자동**으로 잡아 아주 간단합니다. 구름·해·사람·차량 흐름에 좋습니다.

### 밤(별·은하수 이동) 타임랩스 — 앱 필요

- 기본 카메라 타임랩스는 **장노출이 안 돼** 어두운 별을 담지 못합니다.
- **인터벌/장노출 촬영 앱**으로 한 장 **15~30초 노출을 여러 장** 연속 촬영한 뒤(스타트레일 방식), 컴퓨터/앱에서 **이어 붙여 영상**으로 만듭니다.
- 밤은 **무한 초점 고정·낮은 화면 밝기·전원 연결**이 특히 중요합니다.

## 3. 몽골에서 언제 · 무엇을

- **주간:** 초원 위 흐르는 구름, 골든아워의 빛·그림자 변화.
- **밤(신월):** 게르·지형 위로 도는 별. **2026년 8월 13일 출발일이 신월**이라 밤에 별이 잘 보입니다(달빛 없음).
- **바람 약할 때** — 장시간이라 삼각대가 흔들리면 영상이 떨립니다.

## 4. 흔한 실수

- **삼각대 없이/흔들림** → 영상이 떨림. 반드시 고정, 촬영 중 건드리지 않기.
- **배터리 방전·자동잠금** → **전원 연결 + 자동잠금 해제**(1순위 실패 원인).
- **밤을 기본 타임랩스로** → 별이 안 담김. 밤은 인터벌/장노출 앱으로.
- **시간을 짧게** → 변화가 안 보임. 충분히 오래.

## 5. 앱·장비

| 항목 | 내용 |
|------|------|
| 삼각대 | 휴대폰용 + 폰 클램프 — **필수** |
| 전원 | 대용량 보조배터리 + 케이블 — **필수** |
| 낮 촬영 | 기본 카메라 **타임랩스 모드**(무료) |
| 밤 촬영 | 인터벌/장노출 촬영 앱 — App Store에서 "timelapse / interval / long exposure" 검색해 평점·최신·가격 확인(확인되지 않은 앱 이름은 넣지 않음) |

---

### 한 줄 요약

> **낮 = 삼각대·전원·자동잠금 해제 → 카메라 앱 타임랩스 모드로 녹화(자동).**
> **밤(별) = 인터벌/장노출 앱으로 15~30초 × 여러 장 연속 → 이어 붙여 영상.** (삼각대·전원 필수, 신월 밤이 유리.)
