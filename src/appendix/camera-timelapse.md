# 몽골에서 카메라로 타임랩스 찍기 (예: Canon R7)

> 오랜 시간에 걸친 변화(흐르는 구름, 이동하는 그림자, 도는 별)를 **짧은 영상**으로 압축하는 것이 타임랩스입니다.
> 일정 간격으로 여러 장을 찍어 이어 붙이며, 스타트레일과 **같은 인터벌 촬영 계열**입니다. (삼각대·전원 필수)
> 예시는 **Canon R7**로 설명하지만, 인터벌/타임랩스 기능이 있는 카메라면 원리는 같습니다.

---

## ⚡ 빠른 카드 (한눈에)

| 항목 | 값 |
|------|-----|
| 방법 | ① 카메라 **내장 타임랩스 동영상**(쉬움) / ② **인터벌 타이머로 RAW 스틸 → PC 조립**(고급·고화질) |
| 모드 | **M(수동)** — 노출·초점·WB 고정(깜빡임 방지) |
| 인터벌 | 구름 **3~5초** · 해/그림자 **5~10초** · 밤 별 **20~30초**(장노출) |
| 매수 | 결과 길이 = 매수 ÷ fps. 예 **300장 ÷ 30fps ≈ 10초** 영상 |
| 초점 | **MF**로 고정(밤엔 별 확대 초점) |
| IS(손떨림보정) | **끄기**(삼각대) |
| 전원 | **더미배터리/그립/여분 다수**(장시간) |

> 낮이면 구름·그림자, 밤이면 별·은하수 이동. 한 편에 **수십 분~수 시간**이 걸립니다.

---

## 1. 타임랩스란 · 왜 몽골에서

- 오래 걸리는 변화를 몇 초~십몇 초로 압축 → **시간을 눈에 보이게** 만듭니다.
- 고비는 **광활한 지형 + 빠른 구름 + 세계 최상급 밤하늘**이라 타임랩스에 이상적입니다: 초원 위 흐르는 구름, 사구에 드리우는 그림자, 게르 위로 도는 별.
- 스타트레일과 같은 인터벌 촬영이라 **한 번 세팅으로 스타트레일·타임랩스를 동시에** 얻을 수도 있습니다(같은 컷을 궤적으로 합치면 스타트레일, 이어 붙이면 타임랩스).

## 2. 찍는 법

### 방법 ① — 카메라 내장 "타임랩스 동영상" (쉬움)

카메라가 인터벌 촬영 후 **4K/FHD 영상으로 자동 완성**합니다(스틸은 따로 저장되지 않음).

1. 메뉴 **[📷 촬영] → [타임랩스 동영상] → [설정]**.
2. **인터벌**(시:분:초)과 **촬영 매수**를 지정. 화면에 예상 소요 시간과 결과 영상 길이가 표시됩니다.
3. **자동 노출**은 [고정] 권장(매 프레임 자동은 깜빡임을 유발). 동영상 녹화 크기(4K 등) 선택.
4. 삼각대·전원 연결 후 시작 → 카메라가 알아서 촬영·조립.

### 방법 ② — 인터벌 타이머로 RAW 스틸 → PC 조립 (고급·고화질)

1. **M모드·RAW**, 조리개·초점·WB **수동 고정**(깜빡임 방지).
2. 메뉴 **[📷 촬영] → [인터벌 타이머] → [설정]** — 인터벌(셔터보다 몇 초 길게)·촬영 매수(**00=무제한**/최대 99).
3. **[노이즈 감소기능(장기노출시)] → [해제]**(밤 장노출 시, 컷 간격이 벌어지는 것 방지).
4. 촬영한 RAW를 컴퓨터에서 **LRTimelapse + Lightroom**(또는 유사 툴)으로 현상·조립. 화질·플리커 제거·노출 변화 제어가 자유롭습니다.

## 3. 몽골에서 언제 · 무엇을

- **주간:** 초원 위 흐르는 구름, 골든아워에 사구·절벽에 이동하는 그림자.
- **황혼→밤 전환(홀리 그레일):** 노출이 크게 변해 **고급**입니다. 초보는 낮 또는 밤 한쪽만.
- **밤(신월):** 게르·지형 위로 도는 별·은하수 이동. **2026년 8월 13일 출발일이 신월**이라 밤 타임랩스에 이상적(달빛 없음). 밤은 **M·장노출(20~30초)·MF 무한초점·IS off**, 은하수 세팅과 같습니다.
- **바람 약할 때** — 장시간 촬영이라 삼각대가 흔들리면 영상이 떨립니다.

## 4. 흔한 실수

- **자동 노출/자동 WB로 깜빡임(플리커)** → **M·수동 WB·수동 초점**으로 고정.
- **매수·시간 계산 안 함** → 10초 영상에도 300장이 필요. 시간을 넉넉히.
- **배터리 방전** → 전원 확보(1순위).
- **삼각대 흔들림** → 바람·무게 대비, 촬영 중 건드리지 않기.
- **밤에 장기노출 NR 켜둠** → 컷 간격이 벌어져 영상이 끊김. **해제**.

## 5. 장비·소프트웨어

| 항목 | 내용 |
|------|------|
| 본체 | 인터벌/타임랩스 기능 카메라(예: Canon R7) |
| 렌즈 | 밝은 광각(밤) / 상황에 맞는 화각(낮) |
| 삼각대·전원 | 튼튼한 삼각대 + 더미배터리/그립/여분 — **필수** |
| 조립 SW | **LRTimelapse**(플리커·홀리그레일 제어) + Lightroom, 또는 내장 타임랩스 동영상 |
