# 몽골에서 휴대폰으로 스타트레일(별궤적) 찍기

> 몽골 고비의 캄캄한 밤하늘에서 **휴대폰으로 별의 궤적(스타트레일)을 담는 법**을 집중해서 다룹니다.
> 지구가 자전하기 때문에, 카메라를 고정해 두고 오래 담으면 별이 **긴 호(arc), 곧 궤적**을 그립니다. 북쪽 하늘을 향하면 별들이 **동심원**을 그리며 돕니다.
> **하루의 시간 순서**(출발 전 준비 → 해 지기 전 세팅 → 밤 촬영 → 합성·정리)대로 따라 하면 됩니다.

## ⚡ 스타트레일 빠른 카드 (한눈에)

| 항목 | 값 |
|------|-----|
| 방법 | ① 스타트레일 **전용 앱으로 한 장에 누적**(간단) / ② 여러 장 찍어 **컴퓨터에서 합성**(고급) |
| 삼각대 | **필수** — 촬영 내내 절대 움직이면 안 됨 |
| 전원 | **보조배터리에 연결한 채로**(수십 분~수 시간 → 배터리·발열) |
| 방향 | **북쪽(북극성 중심)** = 동심원 / 동·서 = 대각선 / 남 = 완만한 곡선 |
| 초점 | **무한(∞)** 맞추고 **잠금**(밝을 때 미리) |
| ISO | **낮게~중간**(예: 400~1600) — 오래 담으므로 낮춰야 노이즈·하늘 밝아짐 방지 |
| 시간 | **최소 15분**, 원형에 가깝게 하려면 **1시간 이상** |
| 방해요소 | 비행기 모드·방해금지·화면 자동잠금 해제·불빛 차단 |

> 지구 자전 = **15°/시간**. 15분이면 약 3.75°(짧은 선), 1시간이면 15°, 원에 가깝게는 여러 시간.

## 🗺️ 몽골 고비 · 2026년 8월 13일 — 이 시기의 특성

**날짜 — 8/13은 "신월(New Moon)"**
- 2026년 8월 13일(출발일)은 이번 달 **신월**, 트립 기간(8/13~8/17)도 신월 직후라 밤이 **최대로 어둡습니다.**
- 스타트레일에 미치는 영향: **하늘이 어두워 궤적에 별이 아주 많이 남습니다(장점).** 다만 **달빛이 없어 전경(지형)은 어둡게** 나오니, 전경을 살리려면 **블루아워(해 진 직후)에 전경을 밝게 한 컷** 미리 찍어 합성하거나, 약한 손전등으로 잠깐 비추는 라이트페인팅을 쓰세요. (달빛 전경을 원하면 트립 후반일수록 초승달이 조금 굵어집니다.)
- 대략 일몰 20시 전후·천문박명 종료 21:30~22시경(몽골 표준시)부터. **정확한 시각·달 출몰·북극성 방향은 별자리 앱으로 그날·그 위치 기준 확인.**

**지역 — 몽골 고비**
- **위도 약 43~46°N** → **북극성이 지평선에서 약 44° 높이**(동심원 궤적의 중심 고도). 북쪽 하늘에 여유 공간을 두고 구도를 잡으세요.
- **세계 최상급으로 어두운 하늘 · 건조한 고지대 사막** → 별이 많이·선명하게 남고 이슬이 덜한 편(급격한 기온 하강 시 김서림 가능).
- **밤 기온 급강하 + 바람** → 스타트레일은 수십 분~수 시간 촬영이라 **방한·전원 확보·삼각대 무게**가 특히 중요.
- **오프그리드** — 앱 오프라인 다운로드·전원(대용량 보조배터리) 미리 확보.

## 1단계 · 출발 전 준비

### 1-1. 방법 두 가지 — 먼저 고르기

**방법 ① 전용 앱으로 한 장에 누적 (간단·권장)**
- 스타트레일 **전용 모드가 있는 카메라 앱**을 씁니다. 앱이 촬영 내내 빛을 **한 장에 계속 쌓아** 궤적을 만듭니다. 촬영이 끝나면 결과 이미지가 바로 나옵니다.
- 장점: 폰 하나로 끝. 진행 상황을 화면으로 보며 원하는 길이에서 멈춤.
- 예: **NightCap 카메라**의 "스타트레일(Star Trails)" 모드 *(기능·표기는 앱 버전에서 확인)*.

**방법 ② 여러 장 찍어 나중에 합성 (고급·화질↑)**
- **짧은 노출(예: 20~30초)을 수십~수백 장 연속** 촬영한 뒤, 컴퓨터에서 무료 프로그램으로 겹쳐 궤적을 만듭니다.
- 장점: 노이즈·비행기 궤적을 골라 제거 가능, 타임랩스 영상도 덤으로. 단점: 연속 촬영이 되는 앱과 컴퓨터 합성이 필요(4단계).

> 처음이면 **방법 ①**로 시작하세요. 익숙해지면 ②로 화질을 높입니다.

### 1-2. 앱 준비 (집에서 미리 설치)

- **촬영 앱:** 스타트레일 모드 또는 장노출/연속촬영이 되는 카메라 앱 1개. 몽골은 데이터가 안 터질 수 있으니 **미리 설치**.
- (방법 ② 쓸 경우) **합성 프로그램**은 컴퓨터에 미리 준비([4단계](#4단계--합성정리)).

### 1-3. 촬영 계획 — 달·시간·장소

- **달:** 은하수와 달리 스타트레일은 **약한 달빛(반달 이하)이 전경(지형)을 은은하게 살려** 오히려 도움이 되기도 합니다. 다만 **보름달**은 하늘이 너무 밝아 별이 적게 남습니다. 신월~반달 사이가 무난.
- **시간:** 하늘이 완전히 어두워진 **천문박명 종료 후**부터. 길게 담을수록 궤적이 기니 **넉넉한 시간 블록**(1~2시간 이상)을 확보하세요.
- **장소:** 고비 사막은 광공해가 거의 없어 최적. 캠프 불빛·차량 헤드라이트를 등지고, 촬영 중 지나다니는 불빛이 없는 곳으로.

### 1-4. 짐 챙기기 (전원이 핵심)

- **휴대폰용 삼각대 + 폰 클램프(마운트)** — 촬영 내내 미동도 없어야 하므로 튼튼하게. 바람 대비.
- **보조배터리(대용량) + 케이블** — **스타트레일의 최대 관건.** 수십 분~수 시간 촬영은 배터리를 크게 소모하고 발열합니다. **전원을 연결한 채로** 촬영하세요.
- 붉은 손전등, 방한/방풍(오래 기다림), 저장 공간 여유(방법 ②는 수백 장).

**출발 전 체크** ☐ 촬영 앱 설치 ☐ (방법②면) 합성 프로그램 ☐ 삼각대 ☐ 대용량 보조배터리+케이블 ☐ 달 위상·시간·장소 ☐ 방한

## 2단계 · 해 지기 전 (자리·구도·초점)

밝을 때 미리 잡아 두면 밤이 수월합니다.

### 2-1. 삼각대 자리

- **바람 없고 단단한 바닥.** 촬영 중 삼각대가 조금이라도 움직이면 궤적이 끊기거나 흔들립니다. 다리를 넓게, 가방을 걸어 무게 추가.
- 촬영 시간이 기니 **사람·차량이 지나며 불빛을 비추지 않는** 자리를 고르세요.

### 2-2. 방향과 구도 — 어떤 궤적을 원하나

- **북쪽(북극성 중심):** 별들이 **동심원**을 그립니다. 가장 극적인 "소용돌이" 궤적.
  - **북극성 찾기:** 북쪽 하늘, 고도는 대략 **그 지역 위도와 비슷**(몽골 고비는 약 44~48° 정도이므로 지평선에서 그만큼 위) *(정확한 위치는 별자리 앱에서 확인)*. 북두칠성·카시오페아 사이에서 찾습니다.
- **동쪽/서쪽:** 별이 **대각선 직선**에 가깝게 떠오르거나 집니다.
- **남쪽:** 완만하게 휘는 큰 곡선.
- **구도:** 아래쪽에 **지형**(능선·게르·바위·사람 실루엣)을 넣으면 궤적과 대비되어 훨씬 좋습니다. 밝을 때 구도를 정해 두세요.

### 2-3. 무한 초점 맞추고 잠그기

- 밝을 때 **멀리 있는 산 능선 등에 초점**을 맞춰 무한 위치를 잡습니다.
- 밤엔 밝은 별을 화면에서 **확대해 점이 될 때까지** 확인. 서드파티 앱이면 수동 초점 슬라이더를 **∞ 직전**으로.
- 한 번 맞추면 **초점을 잠가** 촬영 내내 유지(렌즈를 건드리지 않는 한 유지됨). 스타트레일은 도중에 초점을 못 고치니 특히 중요.

## 3단계 · 밤 촬영

### 방법 ① — 전용 앱으로 누적

1. 앱을 **스타트레일 모드**로 전환.
2. **초점 무한 고정**(2-3), **ISO는 낮게~중간**(예: 400~1600). 오래 담으므로 ISO가 높으면 하늘이 점점 밝아지고 노이즈가 쌓입니다.
3. **전원(보조배터리) 연결**, **비행기 모드·방해금지**, **화면 자동잠금 해제**(도중에 꺼지지 않게).
4. 촬영 시작 → **화면에 궤적이 쌓이는 것**을 가끔 확인. 원하는 길이(최소 15분, 보통 30분~수 시간)가 되면 정지.
5. 결과 이미지를 저장. 마음에 안 들면 방향·ISO·시간을 바꿔 재촬영.

### 방법 ② — 여러 장 연속 촬영(합성용)

1. 앱을 **연속/인터벌 촬영**으로 설정: **한 장 20~30초 노출, 간격 최소(0~2초), 수십~수백 장**.
2. **초점 무한 고정**, ISO는 한 장이 적정 밝기가 되도록(하늘이 타지 않게). **RAW/고화질**로.
3. **전원 연결·방해금지·자동잠금 해제** 후 시작. 예: 30초 × 120장 ≈ 약 1시간.
4. 끝나면 전부 저장(합성은 4단계).

### 촬영 중 공통 요령

- **절대 삼각대·폰을 건드리지 않기.** 궤적이 끊깁니다.
- **화면 밝기 최소**, 붉은 손전등만. 촬영 방향으로 불빛을 비추지 않기.
- **발열·저온** 모두 배터리에 불리 — 전원 연결 필수, 극저온 시 폰 보온.
- 첫 **테스트로 5분 정도** 짧게 찍어 방향·밝기·초점을 확인한 뒤 본 촬영에 들어가면 실패가 줍니다.

## 4단계 · 합성·정리

### 방법 ①(전용 앱)이면

- 이미 한 장으로 완성돼 있습니다. 사진 앱이나 **Lightroom(모바일)·Snapseed** 등에서 밝기·대비·색만 다듬으세요:
  - 하늘의 뿌연 기(블랙)를 살짝 눌러 궤적 대비↑, 색 캐스트(초록/자홍) 완화, 노이즈 약간.

### 방법 ②(여러 장)이면 — 컴퓨터에서 합성

- **StarStaX**(무료, Windows/macOS)로 수백 장을 불러와 **"라이튼(Lighten)/궤적" 모드로 겹치면** 별궤적 한 장이 만들어집니다. 갭 필링(궤적 끊김 보정) 옵션도 있습니다.
- 대안: **Sequator**(무료, Windows) 등도 궤적 합성 지원.
- 합성한 결과를 Lightroom 등에서 밝기·색·노이즈 마무리.
- **덤:** 같은 연속 사진을 이어 붙이면 **별이 흐르는 타임랩스 영상**도 만들 수 있습니다.

## 흔한 실수 (스타트레일 특화)

- **배터리 방전으로 중간에 꺼짐** → 반드시 **전원 연결**. 스타트레일 1순위 실패 원인.
- **삼각대가 미세하게 움직임**(바람·건드림) → 궤적이 끊기거나 이중으로. 무게·바람 대비.
- **초점이 안 맞음** → 도중에 못 고침. **밝을 때 미리 무한 초점 잡고 잠금**.
- **ISO가 너무 높음/시간이 너무 긺** → 하늘이 점점 밝아져(광害 누적) 별이 묻힘. ISO 낮추고, 하늘이 밝아지면 중단.
- **화면 자동잠금·알림** → 노출 끊김·흔들림. 자동잠금 해제 + 방해금지.
- **너무 짧게** → 15분 미만은 궤적이 짧아 밋밋. 넉넉히.

### 한 장으로 요약

> **삼각대 고정 + 전원 연결 → 밝을 때 무한 초점 잠금 → 북쪽(북극성)으로 구도 → ISO 낮게 → (①) 스타트레일 앱으로 30분~수 시간 누적, 또는 (②) 20~30초 × 수백 장 연속 후 StarStaX로 합성 → 밝기·색 정리.**
